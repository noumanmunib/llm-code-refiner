**LLM Code Refiner**
A hybrid Generate-and-Refine pipeline for balancing correctness and quality in LLM-generated code.

**Overview**
This project addresses the correctness-quality trade-off in LLM code generation through a two-stage approach:

Stage 1: Generate correct code using few-shot prompting (Pass@1 ≥ 0.80)

Stage 2: Refine code quality using three strategies:

LLM-based refinement (semantic understanding)

Rule-based refinement (deterministic transformations)

RAG-based refinement (retrieval-augmented generation)
